<div align="center">

</div>

> Open-source PHP package published on Packagist. Write fluent, readable database queries without raw SQL complexity.

| Feature | Description |
|---------|-------------|
| **Fluent API** | Laravel-inspired syntax for building queries |
| **Security** | Prepared statements prevent SQL injection |
| **Full CRUD** | Insert, Update, Delete, Select operations |
| **Advanced Queries** | WHERE clauses, JOINs, aggregates, raw SQL |
| **Testing** | Comprehensive test suite with Pest PHP |
